### Method learning — eCFR *is* reachable, via the Browser pane

Register entry #4 and `../CLAUDE.md` guidance treat **eCFR.gov as blocked to automated access**.
That is true of **WebFetch**, but **not** of the Browser pane: `navigate` + `get_page_text` on
`https://www.ecfr.gov/current/title-21/...` returns the **complete, current, verbatim** section text
including tables (proven on 113.60, 113.83, 113.100 and 114.80 on 2026-09-17). Use the Browser pane
for CFR text from now on — it is grade **A** and removes the need for govinfo year-frozen PDFs
(which come back as unparseable binary in this environment: no poppler installed, so `Read` on a
fetched PDF fails).

**Browser-pane caveat:** the pane's default tab is **shared with other agents in the session** — a
parallel agent hijacked it mid-batch during this sweep, returning another agent's page. Always
`tabs_create` your own tab and pass `tabId` explicitly.
