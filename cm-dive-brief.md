# US Contract Manufacturing — dive brief (Phase plan agreed 2026-07-25)

Anchor segment: TBD — default recommendation is food/CPG co-manufacturers (founder edge), with a 1-day comparison pass on discrete job shops (where current startup heat is). Pharma CDMO parked as reach option.

## Phases
1. **Scope decision** — pick anchor segment before research starts.
2. **Desk map (~2 evenings)** — treat the CM's operating loop as the value chain: win work (RFQ → quote → tech transfer) → plan (materials, customer-supplied inventory, scheduling/changeovers) → make (production, OEE, yield) → prove (QC, FSQA docs, SQF/BRC + customer audits) → settle (invoicing, deductions, yield true-ups, claims). Per step: cost structure, current software spend, 3-yr changes. Map the CM↔brand seam explicitly (spec churn, forecast volatility, audit duplication, chargebacks). Verify the WTP hypothesis with real numbers (US co-man margins, current software spend), not assumption.
3. **Arena before harvest** — map funded players and incumbents by step FIRST. Seeds to verify (per CLAUDE.md source gate): Keychain, Nulogy, Interlock (interlock-systems.io), Takt (SF, 2025), Paperless Parts, Tulip, MaintainX, Pico MES, plus ERPs (SAP, Epicor, Infor, Plex). Every harvested problem logs its nearest funded competitor.
4. **Operator voice before scoring** — 6–10 Mom Test interviews (co-man owners/GMs/plant managers, 2–3 brand-side co-man managers, adjacent-startup founders) before anything is scored into the tracker.
5. **Harvest, score, triage** — 30–50 problems into tracker/inventory.csv, then EVALUATE per framework.

All work under the rules in /CLAUDE.md.
